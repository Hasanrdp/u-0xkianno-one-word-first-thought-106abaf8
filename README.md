## The entry

One word, the first that came to mind — nothing else:

**snickersnee**

An old word for a long knife, and for a fight fought with such knives.
It is surprising (rare and archaic), vivid (two blades crossing), and
carries a spark of wit in its sound: a snicker and a sneeze folded into
a single word.

## How it works

`main.py` is a small deterministic Python program. It writes the word,
and only the word, to `/output/entry.txt` — 11 characters, no trailing
newline, no extra whitespace. No input, no network, no randomness, no
clock: the same bytes on every run.

```sh
python3 main.py
cat /output/entry.txt
```
